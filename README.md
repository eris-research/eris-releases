# eris releases

Builds of [eris](https://eris.talk) for macOS and Linux, published automatically.

Don't download these by hand: install eris with the command on
[eris.talk](https://eris.talk), and update it with `eris upgrade-and-reboot`.

`latest` is always the newest build. Every build is also kept as its own
release, named after the commit it was built from.
